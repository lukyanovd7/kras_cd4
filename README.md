# The influence of the KRAS driver mutation on the composition and plasticity of tumor-infiltrating CD4 T cells in non-small cell lung cancer

## The code provided here reproduces integration, quality checking, postprocessing and figures from the manuscript. The processed annotated object is deposited on Figshare.

functions.R Contains functions for (post)processing of Seurat objects. 

colors.R Contains color panels for two levels of annotation of the reference used in figures

integration_rpca.R Performs multi-sample integration using the Seurat RPCA algorithm.

milo.R Executes milo pipeline.

annotation.R Reproduces the annotation of the integrated object used in the figures

all_figures.R Reproduces all Figures, Supplementary Figures, Supplementary Tables in the paper
